berikut adalah dokumentasi penuh untuk project saya (progress saya saat ini) yang tedapat di root folder

file "pemindahan memori.md" atau "otak utama" adalah dokumentasi utama (otak dari semua dokumentasi)
file tersebut awalnya ditujukan untuk melakukan pemindahan memori ai-agent saya ke ai agent saya yang lain sehingga mereka bisa berbagi memori dan konteks secara bersamaan. file tersebut sebenarnya sudah memuat sebagian besar deskripsi dari project saya. namun perlu diingat, terdapat informasi yang masih kurang tepat dan kurang jelas, maka dari itu saya membuat file dokumentasi selanjutnya untuk memperjelas konteks dari "otak utama" tersebut

"laporan inspeksi.md" merupakan file hasil inspeksi (yang baru ditemukan oleh ai agent _setelah mengaplikasikan "otak utama") maka dari itu terdapat informasi yang tidak disertakan dari file "pemindahan memori.md", file ini mencangkup beberapa informasi terkait temuan bug/resiko jangka panjang dan progress saya saat ini

"report.md" merupakan infomasi tambahan yang di inspeksi langsung oleh ai-agent ke-3 saya, maka dari itu terdapat beberapa informasi yang sama dengan "otak utama"

"perbaikan error dan bug.md" merupakan file yang cukup penting, karena terdapat laporan perbaikan bug yang telah diperbaiki dari keseluruhan project saya saat ini. namun hanya beberapa bagian yang baru diperbaiki namun tidak secara menyeluruh (masih ada beberapa bug yang belum diperbaiki namun sudah diinspeksi (terdapat di beberapa laporan sebelumnya)

"pemindahan konteks main-web.md" merupakan file inspeksi khusus untuk main-web atau frontend (mungkin sudah ada beberapa konteks yang dibahas di laporan-laporan sebelumnya) tetapi mungkin lebih spesifik ke website frontend saya

"implementasi.md" merupakan file leporan terakhir saya saat ini, yaitu progress penambahan beberapa fitur di main-web (file implementasi ini seharusnya dimasukkan ke dalam file "laporan inspeksi.md" karena memuat beberapa progress yang seharusnya diimput di main web tersebut, tetapi saya memerintahkan ai-agent saya untuk membuat laporan ini untuk menambahkan beberapa informasi spesifik terkait progress terakhir saya
